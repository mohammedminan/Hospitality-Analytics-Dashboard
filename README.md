> 🚀 **Hospitality Analytics Dashboard** :

Analyze hotel booking data to identify trends in occupancy, revenue, customer ratings, city performance, and time-based growth.

📝 **Description/Purpose** :

This project aims to analyze **hospitality (hotel) data** to uncover insights on occupancy, customer preferences, city-wise performance, revenue distribution, and growth trends over time using interactive Excel dashboards.

🧰 **Tech Stack** :

• Microsoft Excel – Data cleaning, transformation, and visualization

• Pivot Tables & Pivot Charts – For summarizing and analyzing large datasets

• Slicers – To create interactive filters for the dashboard

• Data Validation & Formatting – To enhance data usability and presentation

📌 **Feature and Highlights**

• **Goal** :  
To extract meaningful business insights from hotel booking data by identifying trends in occupancy %, customer ratings, city revenue performance, cancellations, and time-based growth, and to present these insights through an interactive and visually engaging Excel dashboard.

• **Walkthrough on Key Visuals** :

**KPI Cards**: Display total bookings, cancellations, successful bookings, revenue, RevPAR, and occupancy %.

**Pie Charts**: Show city-wise revenue contribution (Mumbai, Bangalore, Hyderabad, Delhi) and booking status overview (Checked-out, Cancelled, No-show).

**Line Chart**: Weekly key metrics trend for revenue, ADR, and occupancy % to highlight seasonal or weekly variations.

**Column Chart**: Realization % and Average Daily Rate by booking platform.

**Bar/Column Chart**: Revenue distribution by room class (Elite, Premium, Presidential, Standard).

**Detailed Table**: Property-level insights including RevPAR, occupancy, ADR, realization %, cancellations, and average ratings.

The dataset was provided by my institution as part of a project-based learning module. It included **hotel-level data** such as property name, location, room type, revenue, occupancy, RevPAR, ADR, booking status, and customer ratings, which were used to perform analysis and build a dynamic dashboard.

**Provided By**: Excelr Institution

**File Format**: .xlsx

**Data Fields**: Property ID, Property Name, City, Room Class, Booking Status, Revenue, RevPAR, ADR, Occupancy %, Realization %, Ratings

**Use Case**: This dashboard can help **hotel chains, revenue managers, and market analysts** identify high-performing properties, track cancellations and no-shows, evaluate city-level performance, and monitor growth trends over time. It supports **data-driven decisions** for pricing, expansion, and operational improvements.
